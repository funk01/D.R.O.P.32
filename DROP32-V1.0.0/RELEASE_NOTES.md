# D.R.O.P.32 V1.0.0 — Initial Release

**Wi-Fi in. USB out.**

D.R.O.P.32 is an ESP32-S3 file bridge for moving files to computers that should remain disconnected from a LAN or the Internet. Upload from a modern browser, store files in internal flash or on an SD card, and present the same storage as a writable USB drive.

## Highlights

- Browser-based file and folder transfer
- Internal FAT flash and optional SD storage
- Writable USB Mass Storage mode
- Strict Web/USB storage ownership switching
- Optional integration into a trusted 2.4 GHz Wi-Fi network
- Storage capacity and write-speed dashboard
- Browser-based firmware updates
- Responsive D.R.O.P.32 web interface

For larger files and folder collections, an SD card is strongly recommended.

See the repository README for wiring, installation, credentials, operation and safety instructions.
