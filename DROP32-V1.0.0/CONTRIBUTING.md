# Contributing

Bug reports, test results and focused pull requests are welcome.

1. Search existing issues first.
2. Describe the ESP32-S3 board, storage medium, host operating system and firmware version.
3. Reproduce storage issues using disposable files.
4. Build the project with `pio run` before submitting a pull request.
5. Keep changes focused and document user-visible behavior.

Never include real Wi-Fi passwords, private IP details or personal files in an issue, log or screenshot.
